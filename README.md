# DBMS Lab – 3rd Semester

This repository contains all SQL queries, scripts, and exercises completed as part of the **Database Management Systems (DBMS) Lab** in my 3rd semester.

## 📁 Repository Structure

```
dbms-lab/
├── schema/              # Table creation scripts (CREATE TABLE, constraints)
├── queries/             # SELECT, JOIN, subquery exercises
├── procedures/          # Stored procedures & functions
├── triggers/            # Trigger exercises
├── er-diagrams/         # ER diagrams / schema designs (if any)
└── README.md
```

*(Adjust the folder names above to match however you've actually organized your files.)*

## 🧠 Topics Covered

- DDL (CREATE, ALTER, DROP) and DML (INSERT, UPDATE, DELETE)
- Constraints — PRIMARY KEY, FOREIGN KEY, CHECK, NOT NULL, UNIQUE
- Joins (INNER, LEFT, RIGHT, SELF JOIN)
- Subqueries and Nested Queries
- Views and Indexes
- Stored Procedures & User-Defined Functions
- Control Structures — IF/ELSE, CASE, WHILE, REPEAT
- Cursors
- Triggers (BEFORE/AFTER INSERT, UPDATE, DELETE)
- Aggregate Functions & GROUP BY / HAVING

## 🛠️ Tools Used

- MySQL / Oracle SQL
- MySQL Workbench / SQL Developer
- Git & GitHub for version control

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone <your-repo-link>
   ```
2. Open the `.sql` files in MySQL Workbench, phpMyAdmin, or your preferred SQL client.
3. Run the schema/setup scripts first, followed by the queries or procedures in order.
